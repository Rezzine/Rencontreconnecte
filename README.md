# RencontreConnect

**RencontreConnect** est une application de rencontres respectueuse et inclusive, destinée à tous. Elle met l'accent sur la bienveillance, la liberté d'expression et la création de liens sincères.

## Fonctionnalités principales

- Création de profil utilisateur
- Système de like et de matching
- Messagerie entre utilisateurs
- Interface simple et intuitive
- Respect de la vie privée

## Technologies utilisées

- HTML5 / CSS3 / JavaScript
